# Portafolio

Portafolio profesional de desarrollo de software con interfaz moderna en modo oscuro, secciones animadas, tarjetas de proyectos, formulario de contacto, scroll suave y diseño responsive para móviles.

## Ejecutar localmente

Abre `index.html` en tu navegador o usa un servidor estático:

```bash
python3 -m http.server 4173
```
